# Moonstone public OAuth identity

This repository hosts only public client metadata and public verification keys for Moonstone. It contains no application backend, private signing keys, account credentials or OAuth tokens.

Client metadata: https://ctorstrick.github.io/moonstone-oauth/client-metadata.json

The declared permissions cover planned posting/replies, reply-visibility controls and image/video upload. Metadata publication is not evidence of a connected account, implemented publishing or live operation acceptance.
